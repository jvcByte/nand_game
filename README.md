# NandGame Journey: Building a Computer from NAND Gates

[![NandGame](https://img.shields.io/badge/NandGame-Play%20Here-blue)](https://nandgame.com/)

This repository documents my hands-on journey through **[NandGame](https://nandgame.com/)** — an excellent educational puzzle game where you build a complete computer starting from **nothing but NAND gates** (implemented with relays in the game).

## About NandGame

NandGame teaches the fundamentals of digital logic and computer architecture through interactive levels. You start with a single primitive (NAND) and gradually build:

- Basic logic gates (AND, OR, NOT, XOR, etc.)
- Arithmetic components (adders, ALUs)
- Memory units (flip-flops, registers, RAM)
- Control logic and eventually a full **CPU** capable of executing simple programs

It's a fun, visual, drag-and-drop alternative (or companion) to the famous **Nand2Tetris** course.
